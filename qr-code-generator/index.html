QR Code Generator

Make a QR code from text or a link, with custom colours, and download PNG or SVG.

Everything is worked out in your browser; nothing is sent anywhere or saved.

How to use

  1. Type or paste text or a link.
  2. Pick a size, colours and error-correction level.
  3. Check the live preview and download PNG or SVG.

About QR Code Generator

The QR Code Generator turns text or a URL into a scannable code that updates as you type. Higher error correction keeps a code readable when it is printed small or partly covered, at the cost of a denser pattern. SVG files stay sharp at any print size. It runs entirely in your browser, with nothing sent anywhere or saved.

FAQs

Which error-correction level should I use?

M suits most uses. Choose Q or H if the code will be printed small, outdoors, or with a logo over it.

Do the codes expire?

No. The code holds your text directly, so it works for as long as the link or text inside it does.

Why won't my code scan?

Keep strong contrast with a dark foreground on a light background, and shorten long text.
